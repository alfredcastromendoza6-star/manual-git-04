# Investigación: Solución de problemas de Git

## Introducción

Git es un sistema de control de versiones que permite guardar, organizar y administrar los cambios realizados en un proyecto. Es utilizado principalmente por desarrolladores para llevar un historial de los cambios y facilitar el trabajo individual y colaborativo.

Aunque Git es una herramienta muy útil, durante su utilización pueden aparecer diferentes problemas relacionados con repositorios, ramas, commits, conflictos, archivos y conexiones con repositorios remotos.

Markdown es un lenguaje de marcado ligero que permite crear documentos organizados utilizando títulos, listas, tablas, texto en negrita, enlaces y bloques de código. Por esta razón, Markdown es muy utilizado para documentar proyectos y explicar comandos de Git.

# ¿Qué es Git?

Git es un sistema de control de versiones distribuido. Permite registrar los cambios realizados en los archivos de un proyecto y recuperar versiones anteriores cuando sea necesario.

### Principales características de Git

- Permite registrar cambios.
- Permite crear y administrar ramas.
- Permite trabajar con varias versiones de un proyecto.
- Facilita el trabajo colaborativo.
- Permite recuperar versiones anteriores.
- Mantiene un historial de modificaciones.
- Permite trabajar con repositorios locales y remotos.

---

## ¿Qué es GitHub?

GitHub es una plataforma que permite almacenar repositorios Git en Internet y facilita el trabajo colaborativo entre desarrolladores.

Es importante diferenciar ambos conceptos:

- **Git:** sistema de control de versiones.
- **GitHub:** plataforma donde se pueden alojar repositorios Git.
