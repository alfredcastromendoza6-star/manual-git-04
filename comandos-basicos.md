los **comandos básicos en GitHub** son instrucciones que permiten **trabajar, administrar y controlar proyectos de programación** mediante Git y GitHub. Se utilizan para guardar cambios, crear versiones del proyecto, subir archivos, descargar actualizaciones y trabajar junto con otras personas.

## Comandos básicos

- `git init`: crea un nuevo repositorio de Git en una carpeta.
- `git clone`: copia un repositorio de GitHub en el computador.
- `git status`: muestra el estado actual de los archivos y los cambios realizados.
- `git add`: prepara archivos para ser guardados en una versión.
- `git commit`: guarda los cambios realizados en el historial del proyecto.
- `git push`: envía los cambios del computador al repositorio de GitHub.
- `git pull`: descarga los cambios más recientes desde GitHub.
- `git branch`: permite crear y administrar diferentes ramas del proyecto.
- `git checkout`: permite cambiar entre ramas o versiones.
- `git merge`: combina los cambios de una rama con otra.
- `git log`: muestra el historial de cambios realizados en el proyecto.
